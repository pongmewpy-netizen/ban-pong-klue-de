# แอปธุรการชั้นเรียน โรงเรียนบ้านโป่งเกลือ — รุ่นทดลองมือถือ

## บัญชีทดลอง
- ชื่อผู้ใช้: `ครูทดลอง`
- รหัสผ่าน: `1234`

## รุ่นนี้ทำอะไรได้บ้าง
- หน้าจอมือถือและคอมพิวเตอร์
- รองรับ อ.2, อ.3 และ ป.1–ป.6
- เพิ่ม/ค้นหา/ลบรายชื่อนักเรียนสมมติ
- ทดลองเช็กชื่อ มาเรียน/ขาด/ลา/ป่วย
- ทดลองบันทึกคะแนน กิจกรรมเยี่ยมบ้าน และการติดต่อผู้ปกครอง
- สรุปรายงานและส่งออก CSV
- เก็บข้อมูลไว้ใน localStorage ของเบราว์เซอร์อุปกรณ์นั้น

## ข้อจำกัดสำคัญ
**นี่เป็นต้นแบบเพื่อทดลองหน้าจอและขั้นตอนใช้งานเท่านั้น ไม่ใช่ระบบออนไลน์จริง**
- บัญชีเข้าสู่ระบบเป็นบัญชีทดลองที่อยู่ในโค้ด ไม่ปลอดภัยสำหรับข้อมูลจริง
- ข้อมูลไม่ซิงก์ระหว่างมือถือกับคอมพิวเตอร์
- ยังไม่เชื่อม Supabase หรือระบบยืนยันตัวตนจริง
- ห้ามกรอกชื่อจริง เลขประจำตัว ที่อยู่ เบอร์โทร หรือข้อมูลอ่อนไหวของนักเรียนจริง
- ข้อมูลทดลองอาจหายได้หากล้างข้อมูลเว็บไซต์/เบราว์เซอร์

## วิธีทดลองบนคอมพิวเตอร์
1. ต้องมี Python ติดตั้ง หรือโปรแกรมที่เปิด terminal ได้
2. เปิด terminal ในโฟลเดอร์นี้
3. รัน `python -m http.server 8000`
4. เปิด `http://localhost:8000` ในเบราว์เซอร์
5. เข้าระบบด้วย `ครูทดลอง` และ `1234`

## วิธีติดตั้งบนมือถือเพื่อทดลอง
PWA ต้องเปิดผ่าน HTTPS จึงจะติดตั้งได้อย่างถูกต้อง
1. เผยแพร่ไฟล์เหล่านี้บน static hosting ที่รองรับ HTTPS (เช่น GitHub Pages หรือบริการโฮสต์ static ที่เหมาะสม)
2. เปิด URL ที่เผยแพร่แล้วด้วย Chrome บน Android หรือ Safari บน iPhone
3. Android: เมนูเบราว์เซอร์ > Install app / Add to Home screen
4. iPhone: ปุ่ม Share > Add to Home Screen

## ขั้นต่อไปเพื่อใช้งานจริง
ต้องสร้าง Supabase project, สร้าง schema, เปิด Row Level Security (RLS), ทำ authentication จริง, ตรวจสอบสิทธิ์ฝั่งเซิร์ฟเวอร์, ทดสอบการสำรองข้อมูล และ deploy เว็บไซต์ก่อนนำข้อมูลนักเรียนจริงมาใช้ อย่าเปิด public signup หรือเปิดตารางนักเรียนโดยไม่มีนโยบายสิทธิ์ที่เหมาะสม
